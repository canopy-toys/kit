# canopy-toys

Toy repositories for testing canopy. Nothing here is real work. Tickets are GitHub issues in the `canopy-toys` org.

- **toy-calc** stands alone. `calc/ops.py` holds the operations, `calc/format.py` how a result prints, and
  `calc/cli.py` the argument parsing. `tests/test_cli.py` is the CLI's contract: its exit codes are depended on.

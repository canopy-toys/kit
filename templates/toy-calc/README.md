# toy-calc

A tiny command-line calculator, and a toy repository for testing [canopy](https://github.com/eddieland/canopy).
Nothing here is real work: issues and pull requests are opened, abandoned, and reset freely.

```console
$ python3 -m calc add 2 3
5
$ python3 -m calc --precision 2 div 1 3
0.33
```

Run the tests with `python3 -m unittest -v`. Python 3.10 or later, standard library only.
